# 🛒 Laravel eCommerce Platform

This is a simple eCommerce web application built with **Laravel**, featuring a basic **Admin Panel** to manage products and a **User Frontend** to browse products.

---

## 🚀 Features

### Admin Panel
- Add new products
- Edit existing products
- Delete products
- View all products

### User Panel
- Browse available products
- View product details

---

## 🛠️ Built With

- Laravel 11.x
- Bootstrap 5
- MySQL
- Admin Authentication Middleware
